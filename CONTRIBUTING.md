## Known issues

**Controlled Folder Access Blocked.** To resolve this issue, either add `setup` to the list of allowed apps in Controlled Folder Access or extract the program to a location that is already trusted by Windows.

**Security software held the file back.** A restore from the quarantine list puts `setup` back. Launch that file from the extracted folder.

**`setup` left the folder on its own.** It belongs with the other files. Either return it there or extract the archive again.

**Missing setup file due to folder structure.** The `setup` file may be located in a nested folder. Please navigate one level down until you find `setup` alongside the other files.

**Non-English Windows shows question marks in the title.** Change Region, Administrative, Language for non-Unicode programs to English, or run the build in an account whose language setting matches.
